## 2. `website/src/views/dashboard/ToolPage.tsx` — registry import + lookup + chain

### 2a. Registry import

**Anchor:**

```ts
import { COLD_STORAGE_PAGES } from '../coldstorage';
```

**Insert immediately after it:**

```ts
import { MARKETPLACE_PAGES } from '../marketplace';
```

### 2b. Registry lookup

**Anchor:**

```ts
  const ColdStoragePage = COLD_STORAGE_PAGES[toolId];
```

**Insert immediately after it:**

```ts
  const MarketplacePage = MARKETPLACE_PAGES[toolId];
```

### 2c. `RealPage` chain line

**Anchor** (the tail of the chain):

```ts
    ?? DairyMarketPage ?? BankPage ?? InsurancePage ?? ColdStoragePage;
```

**Replace that line with:**

```ts
    ?? DairyMarketPage ?? BankPage ?? InsurancePage ?? ColdStoragePage
    ?? MarketplacePage;
```

> `MARKETPLACE_PAGES` is placed **last** on purpose: the `orderTracking` tool id is
> already owned by `CUSTOMER_PAGES` (phase-04 WS-03 FarmGate order list), which is
> looked up earlier, so that tile keeps its phase-04 behaviour. Every other
> marketplace tool id (`marketplace`, `wishlist`, `addressBook`, `sellerProducts`,
> `myProducts`) is unique to this registry. The marketplace order list/detail
> pages are reached through the deep routes in §3.

## 3. `website/src/App.tsx` — marketplace deep routes

### 3a. Named import

**Anchor:**

```ts
import { InspectionPage, StorefrontPage } from './views/customer';
```

**Insert immediately after it:**

```tsx
import {
  CartPage,
  CheckoutPage,
  OrderDetailPage,
  OrdersPage,
  ProductDetailPage,
  ProductFormPage,
  ReturnsPage,
} from './views/marketplace';
```

### 3b. Route JSX

**Anchor** (the FarmGate farmer storefront + order inspection block):

```tsx
        {/* FarmGate farmer storefront + order inspection (phase-04 WS-03) */}
        <Route
          path="/dashboard/p/storefront/:farmerId"
          element={loggedIn ? <StorefrontPage /> : <Navigate to="/auth" replace />}
        />
        <Route
          path="/dashboard/p/orders/:orderId/inspect"
          element={loggedIn ? <InspectionPage /> : <Navigate to="/auth" replace />}
        />
```

**Insert immediately after that block:**

```tsx
        {/* Marketplace e-commerce deep routes (phase-05 WS-03).
            Static segments are listed before the dynamic :productId route. */}
        <Route
          path="/dashboard/p/marketplace/cart"
          element={loggedIn ? <CartPage /> : <Navigate to="/auth" replace />}
        />
        <Route
          path="/dashboard/p/marketplace/checkout"
          element={loggedIn ? <CheckoutPage /> : <Navigate to="/auth" replace />}
        />
        <Route
          path="/dashboard/p/marketplace/returns"
          element={loggedIn ? <ReturnsPage /> : <Navigate to="/auth" replace />}
        />
        <Route
          path="/dashboard/p/marketplace/products/new"
          element={loggedIn ? <ProductFormPage /> : <Navigate to="/auth" replace />}
        />
        <Route
          path="/dashboard/p/marketplace/products/:productId/edit"
          element={loggedIn ? <ProductFormPage /> : <Navigate to="/auth" replace />}
        />
        {/* Order list/detail for marketplace orders — the task-engine deep link
            for order status changes points at /dashboard/p/orders/<orderId>. */}
        <Route
          path="/dashboard/p/orders"
          element={loggedIn ? <OrdersPage /> : <Navigate to="/auth" replace />}
        />
        <Route
          path="/dashboard/p/orders/:orderId"
          element={loggedIn ? <OrderDetailPage /> : <Navigate to="/auth" replace />}
        />
        <Route
          path="/dashboard/p/marketplace/:productId"
          element={loggedIn ? <ProductDetailPage /> : <Navigate to="/auth" replace />}
        />
```

> `/dashboard/p/orders/:orderId/inspect` (phase-04) is more specific than
> `/dashboard/p/orders/:orderId`, so it keeps matching first — no behaviour change
> for the FarmGate inspection flow.
